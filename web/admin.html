Security Policy & Authorization Architecture

Strict Firestore Per-User Isolation

Normal users can only read and write documents inside their assigned users/{userId} path. Unauthenticated reads and writes are blocked by security rules.

Privilege Escalation Prevention

Security rules enforce that normal user creation and profile updates cannot alter the role property. Role promotion requires administrator authorization.

No Client Secret Exposure

Firebase Admin SDK credentials and private keys are never embedded in the client applications. Authentication is handled strictly via Firebase Auth tokens.

Admin Route Protection

The Admin Control Panel is segregated at /admin and guards all operations against Firestore role == 'admin' validation before loading any platform telemetry.
